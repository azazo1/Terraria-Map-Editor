## 未完成

- 精灵的逐样式缩略图: `SpriteSheet` 类型在代码里没有实例化或填充, 配置中也不存在样式清单, 实现前需要先造一份样式表并配套素材, 否则画出来的与原版不一致; 生物群系变体选择同样缺数据.
- 脚本 API 每组的深度仍不及原版: 原版各组有十余个方法, 当前是各组的核心读写与统计.
- NBT 浏览器: 选中节点的坐标跳转已可用, 节点上的实体增删入口尚未做.
- 渲染: 已按图集贴图并做坐标变体选帧; 自动拼接 (按四邻选边角帧) 未做. 移植要点已定位: 规则表在 `src/TEdit/Render/BlendRules.cs` (511 行, 含 `GetUVForMasks` 与 base/blend/grass 三级规则), 掩码构造在 `src/TEdit/View/WorldRenderXna.xaml.cs` 5760-5800 行 (边 e=0x1 n=0x10 w=0x100 s=0x1000, 角 ne=0x10000 ... se=0x10000000, strictness 0 普通 / 1 指定合并 / 2 草), UV 缓存字段是 `Tile.uvTileCache`.
- 图标已内置 (方块与墙体图集, 物品与 NPC 图标均来自游戏 XNB), 用户目录仍可覆盖, 仍缺文件时回落色块.
- `Assets/Icons` 有 6992 个小文件, 提交仓库时文件数偏多, 后续可合并为图集加索引.
- 墙体列表的图标仍缺: `Assets/Textures/Walls/{id}.png` 是整张图集, 需要先裁出左上 16x16 帧
  另存为 `Wall_{id}.png` 放进 `Assets/Icons` 才能显示, 目前显示色块.
- 5 星五边形图鉴控件, 旗帜导入文件对话框.
- 玩家编辑器: 外观示意图只表达配色关系, 不是游戏里的真实像素图 (增益列表的编号与时长已可编辑并落盘).
- 图鉴与过滤的精灵分类细化.
- 世界属性中依赖自定义转换器的显示项 (如世界尺寸的文字描述).
- 大世界满屏滚动时的进一步帧率优化 (已完成按块标脏与重绘合并).

## 验证方式

每轮改动都在 GitHub macOS 运行器上执行 `dotnet build -c Release` 与 `--smoke-test`, 通过后发布 `osx-arm64` 产物; 本机不解包构建, 只下载产物供手动试跑.
